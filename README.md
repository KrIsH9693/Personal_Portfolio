> A clean, modern, and responsive personal portfolio built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**, showcasing projects, skills, and education.

---

## 🔥 Features

- Fully responsive layout using **Tailwind CSS**
- Smooth animations with **Framer Motion**
- Interactive project showcase with **hover effects**
- Education timeline with images and descriptions
- Contact section with email and social links
- Gradient headings and modern UI design
- Fast development experience using **Vite + React + TypeScript**
